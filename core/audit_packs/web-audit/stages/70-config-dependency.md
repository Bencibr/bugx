# Stage 70: Config & Dependency Auditing (配置泄露与依赖风险)
<!-- L1:START -->
1. 扫描泄露敏感文件：.git, .env, 备份文件、暴露的 Swagger/Actuator 端点。
2. 检测依赖组件版本，匹配已知 CVE 并进行代码调用链路可达性分析。
3. 验证默认凭证、弱口令与未授权监控/调试接口。
4. 产出配置文件证据片段与实际网络/代码可达性证明。
<!-- L1:END -->
<!-- L2:START -->
## 操作指南
- 对扫描到的 CVE 依赖必须确认应用中确实导入并调用了易受攻击的方法，排除不可达假阳性。
- 对探测到的监控端口提取非敏感环境特征作为存在性证明。

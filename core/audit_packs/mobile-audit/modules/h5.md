# Module: h5（移动端 H5 / M 站）

## 适用
纯 H5 站点或 App 内嵌页面；与 `web-audit` 重叠时以 `web-audit` 的 HTTP/鉴权阶段为主，本模块只补移动端特有面。

## 检查面
- **存储**：`localStorage`/`sessionStorage` 存 token 或 PII；`document.cookie` 缺 `Secure`/`SameSite`。
- **通信**：明文 `http://` 资源、混合内容；WebView 内 `postMessage` 未校验 `event.origin`。
- **点击劫持 / 覆盖层**：`X-Frame-Options`/`frame-ancestors` 缺失；全屏浮层遮挡系统 UI。
- **深链与回跳**：`location.href`/`location.search` 直接跳转（开放重定向）；OAuth `redirect_uri` 未白名单。
- **移动端特有**：`viewport` 缩放锁定、剪贴板读取（`navigator.clipboard`）权限、`geolocation` 授权时机。

## 工具
- 动态：`playwright` MCP（已 active），按移动视口 `deviceScaleFactor` + `isMobile` 运行。
- 静态：`web-audit` 的 semgrep 规则 + 本模块清单。

## 输出
`h5-findings`，每条附 URL、请求/响应或 DOM 证据；无浏览器能力时标 `UNVERIFIED`。

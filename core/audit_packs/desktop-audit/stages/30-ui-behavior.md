# Stage 30: UI Behavior (黑盒：界面行为与本地资源边界)
<!-- L1:START -->
1. 以**黑盒**方式驱动界面：正常路径、边界输入、异常路径、快捷键/拖拽/剪贴板。
2. 观察本地资源访问：文件对话框路径穿越、`file://` 加载、外部链接打开方式。
3. 观察崩溃与卡顿：结合既有 `efficiency` / `memory` 探针采集资源曲线。
4. 产出 `ui-behavior-evidence`。
<!-- L1:END -->
<!-- L2:START -->
## 操作指南
- 只复用既有 `efficiency` / `memory` 探针；**不新造** GUI 自动化框架。
- 需 GUI 会话的用例：能自动化的用宿主能力执行，不能的标注"需人工"，不得伪造结果。
- 崩溃证据必须包含：操作序列、观测现象、退出码/日志片段。
- 本地资源越界访问必须给出"输入 → 访问目标 → 实际结果"三段证据。
<!-- L2:END -->

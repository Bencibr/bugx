# Stage 20: Memory & Concurrency (白盒：内存与并发运行时证据)
<!-- L1:START -->
1. 复用 `memory` 探针采集常驻/堆增长曲线，识别泄漏与增长不收敛。
2. 复用 `concurrency` 探针构造并发/异步时序，验证数据竞争与死锁假设。
3. 使用 ASan/TSan/UBSan 等既有编译器插桩（若工具链允许）获取可复现证据。
4. 产出 `memory-evidence` 与 `race-evidence`。
<!-- L1:END -->
<!-- L2:START -->
## 操作指南
- 只复用既有 `memory` / `concurrency` 探针；**不新造**内存或并发框架。
- 泄漏判定必须给出"观测窗口 + 增长斜率 + 基线对照"，不得仅凭一次采样下结论。
- 竞争/死锁必须给出可复现时序（线程数、操作序列、观测差异）。
- 插桩构建属于**独立产物**：不得污染发布构建；插桩开关与命令必须记录在证据中。
- 无插桩条件时如实标注"仅静态推断，未运行验证"。
<!-- L2:END -->

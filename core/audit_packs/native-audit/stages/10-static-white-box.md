# Stage 10: Static Analysis (白盒：静态规则与数据流)
<!-- L1:START -->
1. 复用 `sast` 探针做静态扫描，按目标语言/构建方式选择规则集。
2. 重点核对：边界检查缺失、整数溢出/回绕、未检查返回值、格式化串、空指针解引用。
3. 每条命中必须给出**代码位置 + 触发条件 + 可达性判断**，禁止只列规则名。
4. 产出 `static-findings`。
<!-- L1:END -->
<!-- L2:START -->
## 操作指南
- 先跑既有 `sast` 探针，**不要**自建扫描器（避免重复实现）。
- 静态命中**不等于**缺陷：必须补"可达性"分析（输入是否可控、路径是否可达）。
- 对编译器/平台相关的结论（如结构体对齐、未定义行为）必须注明目标 ABI 与编译选项。
- 若构建无法在本地完成，标注为"静态可读但无法运行验证"，不得据此判为已确认缺陷。

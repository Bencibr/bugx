# Stage 00: Scope & Target Model (黑盒边界与目标建模)
<!-- L1:START -->
1. 确认目标形态：可执行文件、动态库、静态库、固件或嵌入式镜像。
2. 记录架构/字长/ABI、编译选项来源（构建脚本、CMake/Makefile、交叉工具链）。
3. 界定可测试边界：是否可运行、是否需模拟器/真机、是否允许插桩。
4. 产出 `scope-manifest.json`。
<!-- L1:END -->
<!-- L2:START -->
## 操作指南
- 只做**只读**侦察：`file`、`otool -L`/`ldd`、`nm`、`strings`、`readelf`（按平台选择）。
- 严禁对生产设备/固件执行写操作或刷写；真机测试须用户显式授权。
- 记录**不可自动化**的部分（需真机、需特定工具链）并如实标注，不得假装已覆盖。
- 与后续阶段共享 ABI/字长结论：它决定溢出与内存布局的判定基准。
